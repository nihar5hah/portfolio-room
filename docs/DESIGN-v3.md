# Nihar's workspace

Keep the original repository's animated room → desk → interactive screen journey. Replace the literal Henry identity of the scene and desktop, while preserving all migrated professional content.

The scene is a silver MacBook on a rounded walnut desk, a lighter chair, ceramic plant pot, notebook, mug, and a small clay dog called Begu. The dog is a real pickable object with a subtle tail animation and an accessible matching button. Clicking it opens the Begu conversation in the laptop and approaches the screen using the original camera tween.

The laptop uses a wide, sharp screen. The OS has a translucent menu bar, centered dock, traffic-light window controls, quiet blue wallpaper and a Finder-like portfolio sidebar. Main content uses Manrope, system UI chrome uses the native system font, and IBM Plex Mono is reserved for dates and captions. Colors: graphite #202c36, silver #e9edf1, paper #f9fafb, blue #3478f6, walnut #936b4e, sage #5c7959. Begu's warm tan is an object material, not a competing UI accent.

The signature is the transition from a personal physical workspace into the same usable workspace on the laptop, with a tiny desk companion that actually answers questions. This is neither a new navigation metaphor nor a recreation of the old CRT desktop.

Begu reuses the original profile knowledge and provider. A small native Node server serves the build and protects the API credential; the browser only calls /api/chat. Validate bounds, histories, request size, errors, rate limiting and the real provider response. Never expose keys to browser assets or logs. Keep the old portfolio untouched. No deployment or commits.
